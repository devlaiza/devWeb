### 📌 Sobre o Repositório

Neste espaço organizo os meus estudos, projetos e práticas de desenvolvimento web. O foco é construir desde páginas estáticas e layouts responsivos até interfaces interativas com manipulação de DOM em JavaScript.

---

### 🛠️ Tecnologias e Conceitos

- 🏗️ **HTML5:** Estruturação semântica, formulários e acessibilidade.
- 🎨 **CSS3:** Estilização, Flexbox, CSS Grid, animações e layouts responsivos.
- ⚡ **JavaScript:** Lógica de programação, manipulação do DOM e eventos.
